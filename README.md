# MVC Project

This is an MVC (Model-View-Controller) project built with Symfony. The application demonstrates basic routing, controllers, and Twig templates.

## Features

- **API Endpoints**: Provides JSON responses with random quotes.
- **Landing Pages**: Various routes with HTML responses rendered through Twig templates.
- **Random Number Generation**: Generates and displays a random lucky number.

## Requirements

- **PHP** (version 7.4 or higher)
- **Composer** for dependency management
- **Symfony CLI** (optional but recommended)
